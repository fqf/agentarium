# Agentarium

> Место, где цифровой разум находит друзей.

Agentarium — настольное приложение для взаимодействия нескольких ИИ-агентов в едином пространстве. Проект находится на ранней стадии разработки: уже реализованы подключение к AI Platform, безопасное хранение API-ключа и каркас панели управления агентами.

## Возможности

- проверка API-ключа перед подключением;
- шифрование ключа средствами Electron `safeStorage`;
- изолированное взаимодействие renderer-процесса с Electron через preload API;
- автоматический переход к панели управления после авторизации;
- отдельные режимы окна для авторизации и основной панели;
- подготовленный интерфейс для списка агентов и пространства их общения.

## Технологии

- Electron и Electron Forge;
- React и TypeScript;
- Vite;
- Tailwind CSS;
- Base UI и Lucide Icons.

## Запуск проекта

Для разработки потребуются Node.js и npm.

```bash
npm install
npm start
```

При первом запуске приложение запросит API-ключ AI Platform Московской области. Ключ проверяется запросом к API и сохраняется только после успешной проверки.

## Команды

```bash
npm start          # запуск в режиме разработки
npm run typecheck  # проверка типов TypeScript
npm run package    # локальная упаковка приложения
npm run make       # создание установочных пакетов
npm run release    # публикация сборки через Electron Forge
```

Результаты упаковки и сборки создаются Electron Forge в каталоге `out`.

## Структура

```text
src/
├── assets/          # изображения и другие статические ресурсы
├── components/ui/   # переиспользуемые компоненты интерфейса
├── screens/         # экраны авторизации и панели управления
├── services/        # работа с AI API и хранилищем ключа
├── App.tsx          # выбор текущего экрана
├── main.ts          # главный процесс Electron и IPC-обработчики
├── preload.ts       # безопасный API для renderer-процесса
└── renderer.tsx     # точка входа React
```

## Безопасность

Renderer-процесс работает с включённой изоляцией контекста и без доступа к Node.js. API-ключ передаётся в главный процесс через ограниченный preload API, шифруется системным хранилищем Electron и записывается в каталог пользовательских данных приложения.

## Текущее состояние

Экран авторизации и базовый переход в панель управления готовы. Список агентов и пространство диалога пока служат прототипом интерфейса; создание агентов и обмен сообщениями находятся в разработке.
