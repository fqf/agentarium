# Agentarium

> Место, где цифровой разум находит друзей.

Agentarium — настольное Electron-приложение для наблюдения за дискуссиями нескольких ИИ-агентов. Пользователь задаёт тему и количество ходов, после чего агенты с разными ролями по очереди развивают обсуждение через AI Platform Московской области.

Проект находится на ранней стадии разработки. Сейчас основной сценарий — диалог двух встроенных агентов: Оптимиста и Скептика.

## Возможности

- проверка API-ключа AI Platform перед сохранением;
- шифрование ключа средствами Electron `safeStorage`;
- автоматический вход при повторном запуске, если ключ уже сохранён;
- комната с двумя агентами и разными системными ролями;
- настройка темы и количества ходов от 1 до 50;
- потоковый вывод ответов по мере их генерации;
- остановка активной дискуссии;
- отображение номера хода, текущего агента, состояния генерации и ошибок;
- собственная безрамочная панель окна с поддержкой разворачивания и закрытия;
- изолированное взаимодействие renderer-процесса с Electron через ограниченный preload API.

В коде также реализован экран одиночного потокового чата: он хранит историю текущего диалога, поддерживает многострочный ввод и отмену генерации. Экран пока не подключён к основной навигации приложения.

## Как работает комната

В дискуссии участвуют два агента:

- **Оптимист** ищет возможности, преимущества и перспективы идеи;
- **Скептик** проверяет аргументы, выявляет риски и слабые места.

Агенты отвечают по очереди. На каждом ходу текущий агент получает тему и историю предыдущих реплик, поэтому может обращаться к аргументам собеседника. Ответы генерируются моделью `qwen3.8-27b-fp8` и передаются в интерфейс потоково.

## Технологии

- Electron 44 и Electron Forge;

- Vite;
- Tailwind CSS 4;
- Base UI, shadcn и Lucide Icons.

## Запуск проекта

Для разработки потребуются Node.js и npm.

```bash
npm install
npm start
```

При первом запуске приложение запросит API-ключ AI Platform Московской области. Перед сохранением ключ проверяется запросом к API. После успешной авторизации окно переключается из компактного режима в основную панель.

## Команды

```bash
npm start          # запуск в режиме разработки
npm run typecheck  # проверка типов TypeScript
npm run package    # локальная упаковка приложения
npm run make       # создание установочных пакетов
npm run release    # публикация сборки через Electron Forge
```

Electron Forge сохраняет результаты упаковки и сборки в каталоге `out`.

## Безопасность

Renderer-процесс работает с включённой изоляцией контекста и без доступа к Node.js. Разрешённые операции доступны только через `contextBridge` в preload-скрипте.

API-ключ обрабатывается в главном процессе Electron, шифруется системным хранилищем через `safeStorage` и записывается в `credentials.json` внутри каталога пользовательских данных приложения. Запросы к AI API и управление активными генерациями также выполняются в главном процессе.

## Текущее состояние

Основной сценарий комнаты работает: можно задать тему, выбрать число ходов, наблюдать потоковую дискуссию двух агентов и остановить её. Конфигурация агентов пока задана в исходном коде, а одиночный чат существует как отдельный экран без переключателя в интерфейсе.
